# 🏪 Bordershop - Complete Supermarket Management System

A production-ready, comprehensive Point of Sale and inventory management system built with Next.js 15, Supabase, and TypeScript.

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=for-the-badge&logo=vercel)](https://vercel.com/meshacks-projects-c5f6af07/v0-supermarket-management-system)
[![Built with v0](https://img.shields.io/badge/Built%20with-v0.app-black?style=for-the-badge)](https://v0.app/chat/projects/njPjeVCLulc)

## 🎯 **System Overview**

### **Complete Business Solution**
- 🛒 **Advanced Point of Sale** - Multi-scanner support with AI-powered product suggestions
- 📦 **Inventory Management** - Real-time stock tracking with automated alerts
- 👥 **User Management** - Role-based access control for managers and salespersons
- 📊 **Analytics & Reporting** - Comprehensive business intelligence dashboard
- 💳 **Payment Integration** - Support for cash, cards, and mobile money
- 🏷️ **Professional Barcodes** - Generate and print multiple barcode formats
- 📄 **Receipt System** - Professional receipt generation with multiple output formats

### **Key Features**
- ✅ **Production-Ready**: Complete workflows from product management to sale completion
- ✅ **AI-Powered**: Intelligent product suggestions when barcodes aren't found
- ✅ **Multi-Role System**: Separate interfaces for managers and salespersons
- ✅ **Real-time Operations**: Live inventory updates and instant feedback
- ✅ **Professional Receipts**: Print-ready receipts with proper formatting
- ✅ **Bulk Operations**: CSV import/export for efficient product management
- ✅ **Advanced Barcodes**: Support for EAN-13, UPC-A, Code 128, and Code 39
- ✅ **Comprehensive Audit**: Complete transaction logging and business intelligence

## 🔧 **Environment Variables Configuration**

### **🗄️ SUPABASE DATABASE & AUTHENTICATION** *(Required)*
```env
# Supabase Configuration - Get from https://supabase.com/dashboard
NEXT_PUBLIC_SUPABASE_URL="your_supabase_project_url"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your_supabase_anon_key"
SUPABASE_SERVICE_ROLE_KEY="your_supabase_service_role_key"
SUPABASE_***REMOVED***="your_supabase_jwt_secret"

# Database URLs (automatically generated by Supabase)
POSTGRES_URL="***REMOVED_DB_URL***postgres.xxx:password@aws-0-us-east-1.pooler.supabase.com:6543/postgres?sslmode=require&supa=base-pooler.x"
POSTGRES_URL_NON_POOLING="***REMOVED_DB_URL***postgres.xxx:password@aws-0-us-east-1.pooler.supabase.com:5432/postgres?sslmode=require"
POSTGRES_PRISMA_URL="***REMOVED_DB_URL***postgres.xxx:password@aws-0-us-east-1.pooler.supabase.com:6543/postgres?sslmode=require&pgbouncer=true"
```

**How to get Supabase credentials:**
1. Sign up at [supabase.com](https://supabase.com)
2. Create a new project
3. Go to Settings > API to find your keys
4. Go to Settings > Database to find connection strings

### **💳 PAYMENT INTEGRATIONS** *(Optional but Recommended)*

#### **M-Pesa Configuration** *(For Kenya/East Africa)*
```env
# M-Pesa Daraja API - Get from https://developer.safaricom.co.ke
MPESA_CONSUMER_KEY="your_mpesa_consumer_key"
MPESA_CONSUMER_SECRET="your_mpesa_consumer_secret"
MPESA_PASSKEY="your_mpesa_passkey"
MPESA_SHORTCODE="174379"  # Sandbox: 174379, Production: Your shortcode
MPESA_INITIATOR_NAME="testapi"  # Sandbox: testapi, Production: Your initiator
MPESA_SECURITY_CREDENTIAL="your_security_credential"
MPESA_ENVIRONMENT="sandbox"  # Change to "production" for live transactions

# M-Pesa Callback URLs (set these in your Daraja app configuration)
MPESA_CALLBACK_URL="https://yourdomain.com/api/mpesa/callback"
MPESA_RESULT_URL="https://yourdomain.com/api/mpesa/result"
```

**How to get M-Pesa credentials:**
1. Register at [Safaricom Developer Portal](https://developer.safaricom.co.ke)
2. Create a new Daraja app
3. Get Consumer Key and Secret from app details
4. Generate security credentials using provided tools

#### **Stripe Configuration** *(For Card Payments)*
```env
# Stripe Payment Processing - Get from https://dashboard.stripe.com
STRIPE_SECRET_KEY="sk_test_your_stripe_secret_key"  # Use sk_live_ for production
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_test_your_stripe_publishable_key"  # Use pk_live_ for production
STRIPE_WEBHOOK_SECRET="whsec_your_webhook_secret"

# Stripe Configuration
STRIPE_CURRENCY="kes"  # or your local currency code
STRIPE_COUNTRY="KE"   # or your country code
```

**How to get Stripe credentials:**
1. Sign up at [stripe.com](https://stripe.com)
2. Go to Developers > API keys
3. Copy publishable and secret keys
4. Set up webhooks in Developers > Webhooks

### **📱 BARCODE SCANNER CONFIGURATION** *(Optional)*

```env
# Network Scanner Settings
NEXT_PUBLIC_NETWORK_SCANNER_ENABLED=true
NEXT_PUBLIC_NETWORK_SCANNER_PORT=8080
NEXT_PUBLIC_NETWORK_SCANNER_SECRET="your_secure_scanner_secret"

# USB Scanner Settings (browser-based)
NEXT_PUBLIC_USB_SCANNER_ENABLED=true
NEXT_PUBLIC_USB_SCANNER_VENDOR_ID=1234  # Your scanner's vendor ID
NEXT_PUBLIC_USB_SCANNER_PRODUCT_ID=5678  # Your scanner's product ID

# Camera Scanner Settings
NEXT_PUBLIC_CAMERA_SCANNER_ENABLED=true

# Scanner Behavior
NEXT_PUBLIC_SCANNER_SOUND_ENABLED=true
NEXT_PUBLIC_SCANNER_VIBRATE_ON_SCAN=true
NEXT_PUBLIC_SCANNER_DEBUG_MODE=false  # Set to true for debugging
```

**Scanner Setup Instructions:**
- **Network Scanner**: Use "Barcode to PC" app ([Android](https://play.google.com/store/apps/details?id=com.eme.barcode.pc) | [iOS](https://apps.apple.com/app/barcode-to-pc-wireless/id1179750280))
- **USB Scanner**: Most HID-compatible scanners work plug-and-play
- **Camera Scanner**: Uses device camera with built-in barcode detection

## 🛠️ **Setup Instructions**

### **1. Database Setup**
```bash
# Run the database migrations
npm run db:migrate

# Seed the database with sample data
npm run db:seed
```

### **2. Create Manager Account**
```bash
# Run the setup script to create your first manager account
node scripts/setup_manager.js
```

### **3. Start Development Server**
```bash
npm run dev
```

### **4. Access the System**
- **Manager Dashboard**: `http://localhost:3000/auth/login`
- **Salesperson POS**: `http://localhost:3000/dashboard/salesperson?session=[token]`

## 👥 **User Accounts & Authentication**

### **Manager Authentication** *(Supabase)*
- **Email/Password**: Uses Supabase authentication
- **Default Account**: Created during setup
- **Permissions**: Full system access

### **Salesperson Authentication** *(Custom Token)*
- **Token-Based**: Custom authentication system
- **Account Creation**: Managers create salesperson accounts
- **Permissions**: Limited to POS and personal sales history

### **Creating User Accounts**
```javascript
// Manager creates salesperson account
const salesperson = {
  email: 'john@yoursupermarket.com',
  full_name: 'John Doe',
  role: 'salesperson'
}
```

## 🔒 **Security Configuration**

### **Supabase Security Setup**
```sql
-- Enable Row Level Security
ALTER TABLE products ENABLE ROW LEVEL SECURITY;
ALTER TABLE sales ENABLE ROW LEVEL SECURITY;
ALTER TABLE users ENABLE ROW LEVEL SECURITY;

-- Create RLS policies (see /scripts/security-policies.sql)
```

### **API Security**
- Authentication required for all sensitive endpoints
- Role-based access control implemented
- Input validation on all user data
- SQL injection prevention with parameterized queries
